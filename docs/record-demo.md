# 90 秒演示 · 录制说明

一条命令自己演，你只管按下录制、点她两下、把浏览器切到前面。不剪辑、不配音、不加字幕——她自己的气泡就是字幕。

## 一次准备：OBS，五分钟

```powershell
winget install OBSProject.OBSStudio
```

装完只做四件事，以后每次录都只要点一下「开始录制」：

1. 首次向导选 **仅优化录制**
2. 来源里确认有 **显示器采集**，再加一个 **音频输出采集**（桌面音频）——**不加这个就没有她的声音**
3. 设置 → 输出：录像格式 `mp4`，编码器 `x264`，速率控制 `CQP 20`
4. 输出目录随便挑，别放 C 盘

> 嫌装 OBS 麻烦的话，Windows 自带的截图工具也能录，但录不到桌面音频，她的声音会没了。这段视频最值钱的就是声音，不划算。

## 每次录：三步

1. 桌宠已经在托盘里跑着
2. `node scripts/demo-minimal.mjs --warm`，8 秒，热一下 TTS。这一步**不要录**
3. 点 OBS 开始录制，马上 `node scripts/demo-minimal.mjs`

脚本开头有 8 秒留白，够你从控制台切回桌面。之后按控制台的 `── 第 N 拍 ──` 做动作就行。

## 六拍，约一分半

| 拍 | 控制台提示 | 你做什么 | 屏幕上会看到 |
|---|---|---|---|
| 1 | 她在 | 什么都别做 | 气泡「主人，我在这儿」，口型跟声音对齐 |
| 2 | 点她一下 | 点她脑袋或者腰 | 分区反应，语气词，同一句台词 |
| 3 | 她有脾气 → 哄一下 | 别动 | 黑脸两秒，然后脸红，语气软下来 |
| 4 | 看屏幕 | 把浏览器切到最前面，等着 | 她瞄一眼，说一句屏幕上正在发生的事 |
| 5 | 拖她 | 按住 `Alt` 拖到别处再松手 | 窗口跟手，不闪、不变大 |
| 6 | 收尾 | 别动 | 收尾台词 |

第四拍最考验手速：切浏览器要在提示出现前就切好，她只瞄最前面那个窗口。

## 录完直接用

- 不用剪。真要剪就剪掉开头那 8 秒留白和第四拍万一跳过的那一段
- 标题随便挑一个：
  - `我电脑上住了一只鲸鱼娘`
  - `桌宠会自己看屏幕，还会闹脾气`
  - `写了个桌面宠物，顺手给自己捏了个女仆`
- 简介三行，直接抄：

  ```
  一个 Windows 桌面透明桌宠外壳，接鲸语 Live2D 舞台。
  会说话、有情绪、点哪反应哪、会瞄一眼屏幕。
  代码和装法在 GitHub，README 里有 doctor 自检。
  ```
- 封面我另外出，16:9 无文字，压到 1280×720

## 出问题看这里

| 现象 | 原因 |
|---|---|
| 第一句等了二十多秒 | 没跑 `--warm`，TTS 服务冷启动 |
| 一点声音都没有 | OBS 没加「音频输出采集」 |
| 第四拍跳过、什么都没说 | 浏览器没在最前面，或者探针瞄到了桌宠自己的窗口。把她挪到屏幕边角再试 |
| 她说完还张着嘴 | 看 `data/pet.log` 那行是不是 `play-ok(running)`，不是就贴给作者 |

## 录之前收一收

关掉 QQ、私信、任务栏预览。第四拍会读最前面那个窗口的文字，别把别人的话录进去。
